# 專案需求與技術規格書 (PRD & Tech Spec)

## 一、 專案概述

- **專案名稱：** 台灣大眾運輸私人導航 App (MVP 階段)
- **核心目的：** 解決使用者在異地不熟悉公車/大眾運輸路線、不知該搭哪一班車、容易搭反方向的痛點。
- **目標用戶：** 城市個人用戶，主要載具為台灣大眾運輸（公車、輕軌、YouBike等）。

## 二、 技術架構與選型

- **開發框架：** React Native (搭配 **Expo** 框架)，支援熱重載與 Expo Go 實機預覽。
- **開發環境：** Mac + VS Code。
- **地圖底圖：** OpenStreetMap (OSM) 搭配開源地圖渲染方案（如 `react-native-maps` 或 MapLibre）。
- **外部資料源：** 台灣交通部 **TDX 平台 API**（免費取得全台公車動態、站點與 YouBike 即時資訊）。
- **架構策略（方法 A）：** MVP 階段採用**前端直接呼叫 TDX API**（將 API Key 暫存於前端配置中，以最快速度完成驗證）。

## 三、 第一階段實作目標 (MVP Scope)

請 AI 協助完成以下初始化與基礎功能：

1. **環境與專案建立：**
   - 建立一個新的 Expo + React Native 專案。
   - 配置專案基本結構（Screens, Components, Services）。
2. **地圖模組整合：**
   - 在畫面載入時顯示 OpenStreetMap / 地圖視圖。
   - 取得使用者的手機 GPS 當前位置，並將地圖中心點移動至該位置。
3. **TDX API 串接模組：**
   - 建立一個 API 服務檔案，處理 TDX 的 OAuth2 認證與 Token 取得。
   - 寫一個測試函式，能夠成功呼叫 TDX API 取得指定縣市（例如台北市或高雄市）附近的公車動態資料。

## 四、 給 AI 的執行指令範例

你可以直接對 VS Code AI 說：

> 「我正在使用 Mac + VS Code 開發一個基於 React Native (Expo) 的台灣大眾運輸導航 App。請幫我建立專案骨架，並教我如何在畫面中整合開源地圖（顯示目前 GPS 位置），以及寫一段能夠串接台灣交通部 TDX API 取得公車即時動態的範例程式碼。」
